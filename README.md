A responsive, lightweight web-based quiz application built with vanilla HTML5 and modern CSS3. Designed with a clean interface for presenting questions, monitoring progress, and viewing leaderboard standings.

---

## ✨ Features

* **Clean Modern UI**: Aesthetic card layouts, intuitive typography, and accessible navigation.
* **Responsive Design**: Adapts cleanly across desktop monitors, tablets, and mobile devices.
* **Modular Structure**: Lightweight frontend with zero third-party framework overhead, ready for JavaScript logic or backend API integration.
* **Dashboard & Leaderboard Views**: Pre-structured sections for user profile stats, available quizzes, and ranking tables.

## 🚀 Running Locally

No server installation or build steps required. Simply clone and open:

```bash
# Clone the repository
git clone https://github.com/souradeepdutta/Quiz-website.git
cd Quiz-website

# Open directly in your browser
xdg-open index.html   # On Linux
# or
open index.html       # On macOS
# or double-click index.html in your file explorer
```

Alternatively, serve with Python's built-in HTTP server:
```bash
python3 -m http.server 8000
```
Then navigate to `http://localhost:8000`.
